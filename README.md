# CimentBuild

Plateforme web de vente et de gestion de matériaux de construction, pensée pour téléphone et ordinateur.

Modules : catalogue, recherche, panier, commandes, livraison, stock, fournisseurs, chauffeurs, tableau de bord et administration.

Prix commerciaux : FCFA.
Marché de départ : Togo.

Le projet est prêt pour un déploiement Django/PostgreSQL. Les paiements réels, domaine, comptes marchands et notifications externes restent à connecter avec les informations officielles correspondantes.
