# PROMPT INTÉGRATION PAIEMENT CIMENTBUILD
Objectif : connecter un moyen de paiement réel.

Avant de coder :
1. identifier le prestataire exact ;
2. vérifier sa documentation/API actuelle ;
3. confirmer les prérequis du compte marchand ;
4. identifier les variables d'environnement ;
5. prévoir succès, échec, annulation et vérification serveur.

Ne jamais inventer d'endpoint, de clé, de numéro marchand ou de signature. Les secrets restent dans les variables d'environnement.
