2. identifie les fichiers concernés ;
3. préserve les fonctions existantes ;
4. vérifie migrations et configuration.

- choisis l'architecture la plus simple ;
- garde l'interface mobile ;
- garde les prix en FCFA ;

- indique les variables d'environnement nécessaires ;
- vérifie les erreurs Python/Django évidentes ;
- explique le résultat à un débutant ;
- ne prétends jamais qu'une intégration externe est active sans preuve.
